## Lloyd's Workbench
Author: Lloyd Ryu
## Project Overview
A data-driven application designed to manage and track various projects and tasks. It provides a user-friendly interface for users to create, update, and monitor their work items efficiently.
## Core Features
- Add entertainment and fitness activities to the database
- View and filter activities based on search criteria of Before, On, or After a specified date
- Update activity details by overwriting an existing activitiy in the database their date and time start
- Delete activities from the database based on their date and time start
## Tech Stack
- C# programming language
- .NET Framework
- WPF (Windows Presentation Foundation)
- SQL Server for database integration
- MVVM (Model-View-ViewModel) design pattern
- XAML for UI design
- Git & GitHub for version control
